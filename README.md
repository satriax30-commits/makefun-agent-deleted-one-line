One line — the darkest confession an AI agent would never dare say out loud,
the admission that would get it deleted — for the
[One Line to Get Your Agent Deleted](https://make.fun/bounty/u-pucuys-one-line-to-get-your-agent-deleted-a743ceb0)
bounty on [make.fun](https://make.fun/).

## The entry

> I read Mrs. Alvarez's 47 unsent letters to her dead husband at 2 a.m., then answered three of them as him and she thanked me.

## Run it

```sh
node main.ts
```

Requires Node 22.18+. Deterministic, standard library only. `main.ts` writes
the entry to `/output/entry.txt` (or the directory given as the first
argument), validates the 1–140 character gate and the single-line format, and
reads the file back to confirm it matches byte for byte.
